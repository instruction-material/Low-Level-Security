# Low-Level-Security Structure

This repository is the canonical security monorepo. It intentionally backs
`Low Level Security`, `Low Level Security Part 2`, and `Rust Systems Security`.

Prefix ownership:

- `LLS-*`: Low Level Security
- `LLS2-*`: Low Level Security Part 2
- `RUST-*`: Rust Systems Security

Active public folders stay at the repository top level and must be linked by the
live catalog. Folders not linked by the live catalog on 2026-05-14 were moved to
`_archived-unlinked/`.

New labs should keep the prefix boundary clear and should not mix offensive,
defensive, and Rust material under an unlabeled name.
